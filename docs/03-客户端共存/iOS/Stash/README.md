# iOS：Stash 与懒猫微服共存

Stash 提供两种配置方式，任选一种即可：

| 方案 | 适合场景 | 入口 |
| --- | --- | --- |
| 覆写配置（推荐） | 想一次导入，后续更新订阅也不丢失共存配置 | [覆写配置](./override.md) |
| 手动配置 | 想保留现有配置，只手动添加节点和规则 | [手动配置](./manual.md) |

## 两种方案的共同前提

1. 微服客户端切换到 **Proxy** 模式，并从后台彻底关闭后重新打开。
2. Stash 使用本地节点：SOCKS5 `127.0.0.1:31086`（或 HTTP `127.0.0.1:31085`）。
3. 开启 Tunnel IPv6 路由，并跳过以下地址：`6.6.6.6/32`、`2000::6666/128`。
4. 按对应方案添加微服域名规则：覆写方案已内置；手动方案至少把 `heiyu.space` 分流到本地 `lazycat` 节点。
