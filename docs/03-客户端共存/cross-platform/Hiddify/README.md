# Hiddify 与懒猫微服共存

> 返回：[客户端共存总览](../../README.md) · [文档索引](../../../README.md)

Hiddify 的配置比较简单：开启 IPv6、关闭严格路由即可。

## 配置步骤

1. 打开 Hiddify 客户端，进入“配置选项”。
2. 将 `IPv6` 打开。
3. 将“严格路由”关闭。

![Hiddify 配置截图](https://lzc-playground-1301583638.cos.ap-chengdu.myqcloud.com/guidelines/395/image-20260228140224795.png)

## 验证建议

- 启动 Hiddify 后，确认浏览器可正常访问外网。
- 同时确认 cat 相关域名访问正常（无冲突）。
