# Android：NekoBox（猫箱）与懒猫微服共存

当前仅提供参考视频，具体步骤以视频演示为准。

- [观看 / 下载演示视频](./nekobox.mp4)

## 配置前提醒

1. 先把微服客户端切换到 **Proxy** 模式，并从后台彻底关闭后重新打开。
2. 确认微服客户端「网络模式」页面显示的本地端口（常见为 SOCKS5 `31086` / HTTP `31085`）。
3. NekoBox 中的微服节点、分流规则和绕过路由，按视频演示配置；不同版本的界面可能略有差异。

> 视频使用 Git LFS 存储。如果克隆后无法播放，请执行 `git lfs install && git lfs pull`。
