# 微服内代理部署

在懒猫微服内部运行代理，让微服系统、智慧屏以及微服内的应用可以正常访问外网。

两种方案**二选一**，不要同时启用：

| 方案 | 适合场景 | 特点 | 入口 |
| --- | --- | --- | --- |
| PeppaPig（v2rayA） | 需要透明代理 / 系统代理 | 图形化操作，支持导入代理 URL、连接节点、测试延迟 | [PeppaPig 教程](./PeppaPig/README.md) |
| Clash | 需要 TUN、订阅管理、精细分流 | 支持订阅导入、节点池 / 完整模式、自定义路由、链式代理 | [Clash 教程](./Clash/README.md) |

> 如果不确定选哪个：先用 [PeppaPig](./PeppaPig/README.md) 快速跑通；需要更细的分流、链式代理或 TUN 时再换 [Clash](./Clash/README.md)。

> ⚠️ 开启「自动连接」或让应用接管系统网络前，请先确认 SSH 可用、当前网络配置已测试通过。代理异常时可能导致系统和 SSH 都无法访问。
